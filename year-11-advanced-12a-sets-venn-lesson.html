Set
A collection of things (elements), written in curly brackets.
A = {1, 3, 5}
How many?
|A| or n(A) = number of elements.
Empty set: ∅ and |∅| = 0.
Equal / subset
Equal: same elements, any order.
A ⊆ B every element of A is in B.
A ⊂ B subset, and A is not all of B (proper).
AND = intersection
A ∩ B = in A and in B.
OR = union
A ∪ B = in A or in B (or both).
In maths, “or” always means and/or.
Disjoint
No overlap: A ∩ B = ∅
NOT = complement
Universal set E (everything we are talking about).
Ā or A′ or Ac = in E but not in A.
A ∩ Ā = ∅   A ∪ Ā = E
Counting rule (must memorise)
|A ∪ B| = |A| + |B| − |A ∩ B|
Subtract the overlap because it was counted twice.
If disjoint: |A ∪ B| = |A| + |B|
Fill-from-the-middle
1. Put the both number in the overlap first.
2. Only-A = |A| − both.
3. Only-B = |B| − both.
4. Neither = total − (only-A + both + only-B).
De Morgan (Development Q10)
Ā ∪ B̄ = (A ∩ B) with a bar
Ā ∩ B̄ = (A ∪ B) with a bar
Three sets (Challenge Q18)
|A∪B∪C| = |A|+|B|+|C|
− |A∩B| − |A∩C| − |B∩C|
+ |A∩B∩C|
Pairwise counts include the all-three people.
